# Модулі для кнопки «Замовити модуль»

Фото й QR-коди кладіть у цю папку, а список — у файл `shop.json` у корені сайту:

```json
[
  {
    "name": "АВР TOMZN TOQ5-63/2",
    "photo": "shop/toq5.jpg",
    "qr": "shop/toq5-qr.png",
    "link": "https://посилання-на-магазин",
    "note": "Короткий опис (необов'язково)",
    "price": "від 1 200 грн (необов'язково)",
    "type": "toq5",
    "brand": "tomzn"
  }
]
```

`photo` і `qr` — шлях `shop/...` або повне посилання `https://...`; `link` — лише `https://...`.

`type` (необов'язково) — тип модуля в PanelCraft (кілька — через пробіл чи кому). Якщо такий модуль стоїть на щитку, замість напису EnergyUA на ньому з'являється QR-наліпка з цим посиланням; дотик по ній відкриває великий код. Модуль також потрапляє в розділ «Де замовити» специфікації.

`brand` (необов'язково) — виробник (`tomzn`, `geya`, `se` — Schneider, `abb`…). Коли на один тип є кілька товарів, модуль показує QR того, чий виробник збігається з вибраним у «Налаштувати → Виробник»; для EnergyUA — перший у списку.

Приклади типів: `tovpd1` (TOMZN TOVPD1), `to219` (TO219G), `to119` (TO119G 1P), `toq7` (TOQ7), `g2r` (GEYA G2R-63), `hub` (хаб Zigbee), `kt` / `ktb` / `ktm` (реле часу), `tmr` (таймер добовий), `lc1d` (Schneider TeSys D), `kmc2no`… (модульні контактори).
Застосунок бере список із мережі щоразу, коли відкривають «Замовити модуль», тож оновлювати PanelCraft не треба.
