# ЩитМайстер

Симулятор складання електрощита у браузері.

- **Апарати** — вступний автомат 2P, реле напруги, ПЗВ 30 мА, автомати 1P, диф-автомати, гребінка 1P, шини N і PE на DIN-рейці ЩРН-12.
- **Проводка** — дроти L / N / PE різного перерізу між клемами.
- **Перевірка схеми** — КЗ, кольори дротів, нуль в обхід ПЗВ, групи без ПЗВ, кабель і номінал автомата, перерізи перемичок, селективність, навантаження.
- **Випробування** — подача мережі, регулювання напруги, кнопка «Тест» ПЗВ, імітація витоку й КЗ у групі, перевантаження.

Відкрити: https://genichka.github.io/ShchytMaister/

Навчальний симулятор. Номінали кабелів наведено за поширеною практикою монтажу для мідного кабелю в прихованій прокладці.
