# ЩитМайстер

Симулятор складання електрощитів у браузері: апарати на DIN-рейках, проводка, перевірка схеми і випробування під напругою з демонстраціями.

Відкрити: https://genichka.github.io/ShchytMaister/

## Конструктор і проєкти
- **Новий щит** — майстер: назва, ввід (1 фаза / 3 фази / мережа + генератор / мережа + інвертор з АКБ), корпус (1–4 рейки), шини; далі покроковий помічник складання з перевіркою кожного кроку.
- **Проєкти** — кілька збережених щитів, автозбереження, копія, експорт та імпорт файлу `.shchyt.json`.
- **Обладнання поза щитом** через клемник XT1: двигуни, світло, бойлер, тепла підлога, кран, PV, інвертори, АКБ.
- **«Скасувати»** для будь-якої дії, підписи-наклейки на апаратах, трифазні групи.


## Документи і план (v4.0)
- **Однолінійна схема** будується із зібраного щита: ввід → вступний → реле → ПЗВ → групи, таблиця груп (кабель, довжина, P, Iр, ΔU, споживач). Друк / PDF і SVG.
- **Кабельний журнал** (дроти в щиті з довжинами й наконечниками, кабельні лінії), **специфікація** обладнання (CSV), **маркування** автоматів для друку в масштабі 1:1.
- **План приміщень**: кімнати, щит, розетки, вимикачі, світильники, виводи під прилади; прив’язка до груп, траса по стелі або підлозі, розрахунок довжин кабелю, втрати напруги, коробок, підрозетників, гофри.
- **Виробники й моделі** (ABB, Schneider, Hager, Legrand, Eaton, Siemens, IEK, ZUBR, Digitop, NIK, Eastron, Finder, Новатек) — назви серій звичайним текстом, без логотипів.
- Новий екран: щит на весь екран, панель інструментів знизу (на ПК — праворуч), меню, «Назад/Вперед».

## Шаблони з демонстрацією
- **Квартира** — ввід, реле напруги, ПЗВ, групи на гребінці.
- **АВР на 2 вводи (1 фаза)**:
  - модуль TOMZN (тип TOQ5) + реле напруги перед АВР;
  - модуль GEYA (тип G2R) + реле напруги після АВР, ручний режим;
  - Siemens LOGO! 230RCE + 2 контактори з блокуванням;
  - класична схема на контакторах, реле напруги і проміжному реле;
  - мережа + інвертор з АКБ (модуль TOMZN): перевантаження інвертора, розряд і заряд АКБ, захист від зустрічного ввімкнення.
- **PV DC-бокс** — запобіжники gPV у тримачах (тип TOPV-32), УЗІП DC (тип TZG40-PV), DC-автомат (тип TOB1Z-63): дуга при КЗ стрінга, розмикання тримача під струмом, імпульс блискавки.
- **PV комбайнер-бокс 2 входи / 2 виходи (600 В)** — два незалежні канали на 2 MPPT, тінь на одному стрінгу, обслуговування каналу без зупинки іншого.
- **СЕС** — гібридний інвертор, АКБ, PV, DC-автомати й УЗІП, перемикач обходу 1-0-2, резервні групи.
- **Двигуни** — пуск однофазного (конденсатор) і трифазного двигуна: кнопки, самоутримання, автомат захисту двигуна, реверс зміною фаз, обрив фази.
- **Розумний будинок** — Wi-Fi реле, контактор бойлера, терморегулятор підлоги, хаб Zigbee, лічильник, кран з електроприводом і датчик протікання.

## Що вміє рушій
Кілька вводів (мережа, генератор), три фази, DC, котушки контакторів і реле, кнопки, логіка LOGO!, інвертор як джерело, аварії (КЗ, зустрічне ввімкнення, дисбаланс ПЗВ, перевантаження, обрив фази) з вибором захисного апарата, що спрацює.

## Встановлення на телефон
Відкрийте сайт у Chrome → меню ⋮ → «Встановити застосунок». ЩитМайстер з’явиться з власною іконкою і працюватиме без інтернету.

## Версія й оновлення
Номер версії й дата — у шапці. Кнопка «Оновити» порівнює версію з `version.json` на сайті і встановлює нову лише після підтвердження.

## Збирання
Код лежить у `src/`. Скрипт `build.sh` збирає з частин `index.html` і генерує `version.json` з `src/00_version.js`. Для нової версії змініть номер, дату й список змін у `src/00_version.js`.

Навчальний симулятор. Моделі апаратів спрощені.
